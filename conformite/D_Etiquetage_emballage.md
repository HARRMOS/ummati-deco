# D — Étiquetage de l'appareil et de l'emballage

## 1. Étiquette sous l'appareil (obligatoire)

> Étiquette imprimée résistante (polyester) ou gravure directe dans le socle. Lisible, indélébile.

```
AYAH « Radio »            Modèle : AY-R1
Lot : AY-R1-2026-001      N° : 0001
INOMA — [adresse postale] — [e-mail ou site]
5 V ⎓ [x] A — USB-C
Code d'appairage : XXXX-XXXX        (si prévu, unique par appareil)
CE   [poubelle barrée]   Fabriqué en France
```

| Mention | Règle | Statut |
|---|---|---|
| Marquage **CE** | Hauteur ≥ 5 mm, proportions officielles, apposé **après** la déclaration | ☐ |
| **Poubelle barrée** (DEEE) | Symbole de la norme EN 50419 ; barre noire sous la poubelle si exigée (date de mise sur le marché) **[À VÉRIFIER]** | ☐ |
| Nom, raison sociale ou marque **et adresse postale** du fabricant | Plus un moyen de contact électronique (GPSR) | ☐ |
| Type / modèle + numéro de lot ou de série | Pour la traçabilité | ☐ |
| Caractéristiques d'alimentation | 5 V ⎓, courant | ☐ |

Si la place manque sur l'appareil, certaines mentions (adresse) peuvent figurer sur l'emballage et la notice **[À VÉRIFIER selon chaque texte]** — le CE, le modèle et le lot restent sur l'appareil.

## 2. Emballage

| Mention | Statut |
|---|---|
| Nom du produit, modèle, lot | ☐ |
| Fabricant + adresse + contact | ☐ |
| Marquage CE (recommandé aussi sur la boîte) | ☐ |
| Poubelle barrée | ☐ |
| **Logo Triman + Info-tri** pour l'emballage et le produit (règles françaises de tri) — **[À VÉRIFIER : modèle à jour fourni par ton éco-organisme emballages]** | ☐ |
| « Chargeur non fourni » | ☐ |
| « Ce n'est pas un jouet » / « Ne convient pas aux enfants de moins de 3 ans » (si petites pièces) | ☐ |
| Pas de mention trompeuse (« certifié », « norme CE validée par… », logo Bluetooth si non inscrit) | ☐ |

## 3. Notice

La notice (C) accompagne chaque appareil, en français. Elle contient la déclaration de conformité simplifiée et les consignes de sécurité.

## 4. Mentions interdites ou à éviter

- « Approuvé par l'Union européenne », « certifié CE » : le CE est une **auto-déclaration**, pas un label.
- Logo ou mot **Bluetooth** si non inscrit au Bluetooth SIG.
- Logo **Wi-Fi CERTIFIED** sans certification Wi-Fi Alliance (le mot « Wi-Fi » descriptif reste possible **[À VÉRIFIER]**).
- Promesses environnementales générales (« écologique », « neutre en carbone ») : encadrées par la loi.
